Settings — five ways to lose the hairline

Same screen, same nine rows, same tokens. The only thing that changes is how one row is separated from the next — the flat 1px rule you called bland. Each frame below is the real file, live and clickable.

How to judge them. A replaces the rule with a lifted card. B removes lines entirely and separates with type and a dot leader. C is the structural one — it promotes Color Studio to a hero panel and demotes the hairline to an internal card divider. D keeps a divider but makes it an ornament. E uses alternating tonal bands and no lines at all.

All five use the locked palette from constants/blackrose.ts, the 12 / 16 / 28 radius scale, Playfair Display for labels and Plus Jakarta Sans for body — nothing here invents a token, so whichever you pick ports straight into SettingsAccordionSection.
