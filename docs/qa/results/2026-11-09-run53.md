## What shipped

- `utils/writingDay.ts` (+32 lines, pure): `canWriteOnDay(dateKey, todayKey)` refuses blank/corrupt/impossible/future keys AND non-string values; `backfillCreatedAt(dateKey, todayKey, now)` returns local NOON on a past day (matching `formatWritingDay`'s `T12:00:00`), `undefined` for today, and refuses any time later than the real clock so a stale screen left open past midnight cannot date an entry into the future. No clock read inside the builder.
- `components/insights/WriteOnDayButton.tsx` (new, 48 lines): ONE shared door for both grids. Empty day: "Nothing written on this day." + 44px "Write about this day" button. Filled day: "Add another note for this day". Future day: no button. Opens `/chat` with `{ writeOn: dateKey }`. Both schemes on every token.
- `app/monthly-review.tsx` (233 lines) and `app/writing-year.tsx` (232 lines): compute `todayKey` once via `getLocalDateKey()` and render the shared button with `canWriteOnDay(selectedDay, todayKey)`. The duplicate empty text was REMOVED from both (one source of truth).
- `components/insights/MonthlyDayPanel.tsx`: empty branch is now `null`; the shared component owns that copy.
- `app/chat.tsx`: `writeOn` param sanitized with `canWriteOnDay`, `writeOnCreatedAt` derived via `backfillCreatedAt(writeOn, todayKey, Date.now())`, kept in `persist.routeParams` and `useChatSessionFlush`'s routeParams so a resumed draft stays on that date. Quiet header note "Writing on Wednesday, October 7, 2026" (`write-on-day-note`) so the writer knows the date. No AI host/key/model touched.
- `hooks/chat/useJournalChatFinish.ts`: new `writeOnCreatedAt?: number` option, applied ONLY in the `create({ ...createdAt })` branch, never `update()` (editing an existing entry must not move its date), and included in the `useCallback` deps. Existing finish side effects already use `savedEntry.createdAt`, so digests/memory follow the chosen day automatically.
- No new storage key, no new storage reads (R2), `utils/` pure, `services/` untouched, `app/` -> hooks intact, no roadmap md.
- Tests: `__tests__/utils/writeOnDay.test.ts` 10, `__tests__/screens/writeOnDayWiring.test.ts` 7, `__tests__/hooks/useJournalChatFinish.writeOnDay.test.ts` 4 (real behavior: create receives the date, ordinary finish leaves it alone, edit never moves it), `__tests__/screens/monthlyDayTapWiring.test.ts` updated (29 total across the four suites).
