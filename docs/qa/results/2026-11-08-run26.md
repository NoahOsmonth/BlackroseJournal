# QA run 26 — pick a letter's unlock day instead of typing it (#51)

Typing `YYYY-MM-DD` into a letter is easy to get wrong, and the mistake was only explained *after* the fact by a validation line. It is now three quick choices and a calendar.

## What replaces the text field

**Quick choices** — In a week · In a month · In a year, each labelled with the real date, e.g. *"Open in a week, on Sunday 15 November 2026"*.

**A calendar** — the next six months, Monday-first, with the 1st under its true weekday so the grid reads like a wall calendar rather than a run of numbers.

**Plain confirmation** — *"Opens on Tuesday 8 December 2026"*.

## Rules that make it safe

- **Days already gone are shown but cannot be chosen.** Hiding them would make the month look broken; dimming them keeps the calendar honest and the intent obvious.
- **Month arithmetic clamps instead of overflowing.** 31 January + one month is 28 February, not 3 March — the classic `setMonth` bug, with a test for it.
- **Impossible days are rejected, not rolled over.** `2026-02-31` is refused rather than quietly becoming 3 March.
- **Leap years are real.** February 2028 has 29 days; a test asserts it.
- **The picker never reads the clock.** The screen passes a `todayKey`, so the pure layer stays deterministic and testable.
- `utils/letters.ts` still owns the date maths and the existing past-day refusal; the picker only produces a day key.

## Verified live

Opened a new letter and read the picker back from the running app:

| Check | Result |
|---|---|
| Picker present | `true` |
| Initial date | *"Opens on Friday 8 January 2027"* |
| Quick choices | *"Open in a week, on Sunday 15 November 2026"*, *"Open in a month, on Tuesday 8 December 2026"*, *"Open in a year, on Monday 8 November 2027"* |
| Tapping "In a week" | field became *"Opens on Sunday 15 November 2026"* |
| Tapping "In a year" | field became *"Opens on Monday 8 November 2027"* |
| Past days | *1 Nov*, *2 Nov*, *3 Nov 2026* all marked disabled |

The dates themselves are correct arithmetic: 8 Nov + 7 days = 15 Nov; +1 month = 8 Dec; +12 months = 8 Nov 2027.
