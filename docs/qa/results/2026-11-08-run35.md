# QA run 35 — the Archive header claimed a filter the screen never applies

Card #62 sweep. Same technique that found run 34: compare two things rendered on one screen.

## The contradiction

Insights was not the only screen with a week label. The Archive header read:

```
This week · Nov 8–14
```

and directly underneath it the feed ran:

```
Today · November 8
Yesterday · November 7
Fri · November 6
Wed · November 4
Mon · November 2
Fri · October 30     <- three of these are not this week
```

`formatWeekMeta` builds the line from `buildWeeklyHistorySummary`, which **does** correctly filter to 8–14 Nov. But the feed itself is `groupHistorySections(items)` over **every item ever written** — grouped by day, no week boundary. So the header described a window the list did not honour.

This is the same class as run 34 (mood strip vs week header) but the opposite way round: there the data was wrong and the header right; here the header's *range* is right but it implies a filter that does not exist.

## Why not filter the list

The design source (`black-rose-archive.png`, `docs/plans/blackrose-design-rewrite.md`) specifies the "This week · Jan 18–24" line but never says the archive is week-scoped — and an archive that hides older entries on the tab called **Archive** would be worse than the mislabel. Scrolling back through everything is the point of the screen.

## The fix

`formatWeekMeta(summary, { spansBeforeThisWeek })`:

| Feed contents | Header |
|---|---|
| Fits inside this week | `This week · Nov 8–14` |
| Reaches past this week's start | `This week and earlier · Nov 8–14` |

`app/(tabs)/entries.tsx` computes the flag by comparing the earliest section's `dateKey` against `weeklySummary.weekDayKeys[0]`, so the line changes only when the older rows are actually present.

## Verified on the running app

```
HEADER: Archive  This week and earlier · Nov 8–14  Drafts
DAYS:   Today · November 8 / Yesterday · November 7 / Fri · November 6 /
        Wed · November 4 / Mon · November 2 / Fri · October 30
```

The line now describes every row under it.

## Tests

`__tests__/hooks/historyWeekMetaSpans.test.ts` (4 tests) — short form when the feed fits, "and earlier" when it does not, month-crossing weeks (`Oct 26–Nov 1`) without repeating a month, and `null` for a malformed label.

Sabotage-verified: forcing `lead` to the bare `'This week'` turns 2 of 4 red.
