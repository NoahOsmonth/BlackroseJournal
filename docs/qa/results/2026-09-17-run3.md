## Environment discovery worth keeping

The app's default theme preference is **Dark** (`DEFAULT_SETTINGS_STATE` in `hooks/theme/useThemeSettings.ts`) and the preference is stored as `user-theme-preference`. Playwright's `emulateMedia({ colorScheme })` therefore does **not** change the app's palette on its own - the preference decides, and its absence means dark. Set the preference before any light-mode capture, or the "light" screenshot is really a dark one. (This is why the first AUTH-10 attempt appeared stuck-dark; it was a QA-harness mistake, not an app defect.)

The other environment trap: this machine sets `HTTP_PROXY=http://127.0.0.1:8118`, so the tailnet gateway IP is unreachable from the browser while `localhost` works. Run QA against `http://localhost:54321`.
