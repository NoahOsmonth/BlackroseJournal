## DEF-030 fix (same day)

Both halves are fixed and verified.

- **Finish can no longer re-save a finished chat.** `finalizePersistedSession` drops the stored session and mints a fresh conversation id in the same commit, so the debounced autosave has no old id to write back to. Close (draft save) keeps its previous behaviour and was reverted to `clearPersistedSession` after the hook tests showed the shared helper already moves to a new chat.
- **A chosen AI stays chosen.** `pickModelAfterFetch` no longer replaces a deliberate choice with the first listed option, and the stored profile keeps a selection the refreshed catalogue omits, adding a stand-in entry so the AI shows up in the picker.
- The old test asserting the opposite ("drops a stored selection that is no longer in the catalogue") was rewritten to record the new rule rather than deleted.

Live verification, same session:

- With a deliberate draft typed in an earlier navigation still in the store, pressing Finish in a fresh chat left `sessionsAfter: []` and Drafts read "No drafts yet".
- Clearing the saved AI, pressing Find AI options, then re-choosing `global:hy4free` kept the header at `global:hy4free · 128k memory`.

QA-created entries and drafts were removed afterwards; Archive is back to the five real entries.
