## What changed in the sweep

Round 55 measured five routes. It never measured the two biggest surfaces,
because both need a real record to render:

Round 56 added them plus goals, prompt shelf, on-this-day, streak view and drafts.
That needed a fix to the probe first: it looked for a key ending `:@journal_entries`
and found nothing, so entry detail was silently skipped. The real key is

the payload nests `entries` as an id-keyed map. **A skipped route looks exactly
like a passing route.**

## The headline defect: a border colour used as text

`/streak-view` reported **7 low-contrast labels in both schemes**. They were the
weekday captions (S M T W T F S):

```
fg rgb(44, 42, 38) on bg rgb(12,12,14)  →  1.4:1
```

Cause: `HAIRLINE_TEXT = 'text-hairline-light dark:text-hairline-dark'`. Those
tokens are **border** colours — `#E2DCD2` light, `#2C2A26` dark. As text they
measure **1.2:1 light / 1.4:1 dark**, i.e. invisible in both schemes. It shipped
because a faint divider colour and a faint caption colour look identical in code.

Fixed to a text token (`text-text-secondary-light dark:text-text-secondary-dark`).
Re-measured: **7 → 0** in both schemes.

## The two remaining chat "defects" are not defects

Both are 22×22 icon glyphs (attach a photo, read aloud) that now carry
`hitSlop={12}` → a **46px** target. The probe cannot see that: hitSlop lives in
RN's responder, not CSS, so the rect stays 22px. They are pinned in source by
`iconControlTargets.test.ts` instead. Reporting them honestly beats teaching the
tool to guess.

## Fixed this round

| Where | Measured | Fix |
|---|---|---|
| streak-view weekday captions | 1.4:1 dark / 1.2:1 light | text token, not a border token |
| chat attach-a-photo | 22px + slop 8 = **38px** | slop 12 = 46px |
| chat read-aloud | 22px + slop 8 = **38px** | slop 12 = 46px |
| chat persona pill | 20px tall | `min-h-11` |
| chat thinking toggle | 24px + slop 6 = 36px | slop 10 = 44px |
| goals add line | 21px tall | `min-h-11` |

The two 22px glyphs matter most: they are the most-tapped controls in the app and
were the least tappable things on screen.
