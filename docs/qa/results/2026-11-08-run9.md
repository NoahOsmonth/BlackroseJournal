# QA Run 9 — 2026-11-08

Slice 2 of the ProductOps epic: ship the first feature candidate, `on this day` resurfacing (Kaneo card `huuqilzgk3tisq92rrnfq2pd`).

## What shipped

- Today gains a quiet ON THIS DAY row when the writer has an entry from the same calendar date in an **earlier year**.
- Label is plain wording: `A year ago today`, `Two years ago today`, ..., plus the writer's own title and first words.
- Tapping it opens the saved entry or check-in.
- Nothing new is stored: the row reads the journal and check-in collections Today has already loaded, and the calendar day is derived in memory from each item's timestamp.
- The row hides completely when there is no earlier year, so an empty journal looks unchanged.

## Files

- `utils/onThisDay.ts` — pure selector `pickOnThisDay(entries, now)`: skips today, other dates and later years; prefers the oldest matching year; labels the span in words; returns `null` when nothing qualifies.
- `hooks/today/useOnThisDay.ts` — memoized bridge over `useJournalEntries` + `useIntentionCheckIns`, reusing `buildHistoryItems`.
- `components/today/OnThisDayRow.tsx` — prose row with hairline card, `SectionLabel` caption, no new colors.
- `app/(tabs)/today.tsx` — renders the row between intentions and goals.
