### Three real design flaws the tests caught before shipping

1. **Ancient blanks consumed rest days.** The first algorithm read old-to-new, so empty days from before the writer ever started used up the weekly allowance and broke a live streak. Fixed by deciding rests **newest-first**.
2. **Trailing silence looked like a holiday.** A blank day followed by a week of silence was being forgiven, so 8 days with no writing still read as a streak. A rest now requires writing to **come back** within the next 7 days.
3. **Streak counted forwards.** Old misses erased the current habit. Current streak is now counted **backwards from today**; today with no words is `pending` (still time to write) — neither counted nor allowed to break.

Sabotage: removing the Clear History step `['writing goal', clearWritingGoalSettings]` turned **3 tests red**; exact inverse restored **40 tests green**.
