7. ego-browser `page.goto` timed out on the cold rebuild; fixed with `waitUntil: 'domcontentloaded'`, `timeout: 60000` and a longer explicit wait.
8. First light-scheme flip did nothing: I wrote `JSON.stringify('light')` into `user-theme-preference`; the hook reads a RAW string. Fixed to `'light'` -> `isDark:false` and light colors measured. Round 43 lesson repeated.
9. REAL A11Y FINDING: `aria-valuenow`/role were absent in the DOM. Root cause traced in `node_modules/react-native-web/dist/cjs/modules/AccessibilityUtil/propsToAriaRole.js`: RN-Web maps `adjustable`->`slider`, `button`->`button`, but has NO `progressbar` entry; `createDOMProps` also does not destructure the native `accessibilityValue` object on a plain View. Adding raw `aria-*` + `role` props did not survive NativeWind's cssInterop either (verified the bundle contained them while the DOM did not). Resolution: keep the native `accessibilityRole`/`accessibilityValue` for iOS/Android, and rely on the plain-language `accessibilityLabel` ("2 of 4 written") for the web reader; removed dead web-only props instead of shipping code that does nothing. No claim that a web `progressbar` role exists.
10. `//` comment placed inside a JSX opening tag; moved above the component to avoid fragile markup.
