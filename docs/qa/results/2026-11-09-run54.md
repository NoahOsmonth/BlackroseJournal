## Root cause

`app/(tabs)/today.tsx` called `useFocusEffect(refreshAll)` on EVERY focus, firing `refreshEntries + refreshCheckIns + refreshIntentions + refreshGoals`. Each does a full parse of its whole collection (journal = index + 16 shards). `app/(tabs)/entries.tsx` did the same with `refreshFeed()`. The hooks' `hasLoadedRef` already prevented the skeleton flash (R1), but the redundant parse still blocked the main thread.

## Why NOT a cache

Round 32 reverted a settled-value cache: direct writers (backup restore, demo seed, Explore notes) bypass the hooks and left it stale. `services/account/accountScopedStorage.ts` documents this. So the fix is a **change bus**, not cached data: every write re-reads through the same coalesced adapter, so nothing is masked.

## What shipped

- `services/account/accountScopedStorage.ts`: `subscribeCollectionChanges(listener)` + `notifyCollectionChanged(ownerKey)`. `setItem`/`removeItem` are now `async`, `await` the real write, and notify ONLY after it succeeded (a failed write never signals). The listener gets the UNSCOPED owner key, never account data. A broken listener is caught so it cannot break a storage write.
- `hooks/collections/useCollectionRefresh.ts` (new, 31 lines): subscribes a hook to its owning keys; a burst of shard writes collapses into ONE microtask-scheduled refresh (`if (scheduled) return;`).
- All 4 hooks (`useJournalEntries`, `useIntentionCheckIns`, `useIntentions`, `useGoals`) subscribe with module-level stable key arrays. Journal watches `@journal_entries` plus all 16 `@journal_entries_shard:<n>` keys; the others watch `@intentions`, `@intention_checkins`, `@goals`. Verified those literals against the services' own constants.
- `app/(tabs)/today.tsx`: removed `refreshAll` and `useFocusEffect` entirely. The redundant `refreshGoals()` after `createGoal` was dropped too - the bus now refreshes `useGoals` even though `createGoal` is a direct service call.
- `app/(tabs)/entries.tsx`: dropped `refreshFeed()` from the focus effect; kept only the small `getMostRecentActiveSession()` draft-banner check (a different key, cheap).
- No new storage key, no new outbound host, `utils/` untouched, `services/` never imports hooks/components, one owner per key preserved.
- Tests: `__tests__/services/collectionChangeBus.test.ts` 6, `__tests__/hooks/useCollectionRefresh.test.ts` 3, `__tests__/hooks/directWriteRefreshesCollection.test.ts` 1 (real behavior), `__tests__/screens/tabSwitchStutterWiring.test.ts` 7. Portable paths via `relPosix`.
