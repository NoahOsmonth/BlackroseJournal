## Gap survey → choice

`moodFilter`, `filterByMood`, `activeMood`, `moodChip`, `moodOptions`, `moodPills` = **0 hits**. The Archive had search + starred + topic chips (round 39) but **no way to filter by the feeling**. `HistoryItem.mood` already exists, `utils/moodStrip.ts` `plainMoodWord()` already strips emoji from stored values like `Calm 😌`, and the demo seed has real plain moods (Calm, Curious, Hopeful, Proud, Steady, Tender, Tense, Unsettled, Warm, Reflective). So this is **zero new storage key, zero AI, zero network, zero native build** — it reuses data the feed already loaded.
