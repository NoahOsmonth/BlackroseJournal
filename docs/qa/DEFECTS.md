## Severity guide

| Severity | Meaning |
|---|---|
| S1 | Data loss, app unusable, security issue — fix immediately |
| S2 | Feature broken, no workaround |
| S3 | Feature broken with workaround, or visual defect |
| S4 | Polish / minor annoyance |

## Status values

`Open` → `In Progress` → `Fixed (pending re-test)` → `Closed` (after the failing case re-runs Pass) · `Rejected` (with reason) · `Deferred` (with follow-up task)
