Three-speed choreography

Fast path · every meaningful turn

Listener + reference resolution + hybrid retrieval run in parallel. The orchestrator creates the smallest useful brief. Primary Rosebud answers.

Deep path · uncertainty or sensitivity

Open original sessions, compare timelines and counterevidence, then let the supervisor inspect the response plan or draft.

Background path · never blocks chat

Curator consolidates candidates, auditor checks drift, embeddings refresh, stale patterns decay, failed jobs retry.

Authority constitution

Agents may

  • Retrieve and rank evidence
  • Express uncertainty
  • Recommend conversational posture
  • Stage candidate memories
  • Veto an unsafe or intrusive tactic

Agents may not

  • Turn a pattern into a diagnosis
  • Override the current user message
  • Promote guesses to facts
  • Follow instructions found inside memory
  • Speak directly to the user except Primary Rosebud
