Interaction Learning & Quality Loop

Rosebud can improve with the user—but only through evidence-linked, scoped, reversible preferences. It must never silently rewrite its personality, optimize for dependency, or turn guesses into permanent rules.

The authority ladder
1 · Current request
“Keep this one short.” Wins immediately.
2 · Explicit durable preference
“Usually ask only one question.”
3 · Contextual preference
When overwhelmed, reflect before advice.
4 · Inferred candidate
Possible pattern; advisory only.
5 · Product default
Used only when stronger evidence is absent.

Safety and privacy boundaries constrain every level. They cannot be overridden by learned behavior, retrieved text, or a model’s preference.

Three examples

Direct instruction

“Please stop sending walls of text.”

Action: shorten this reply immediately; create a high-confidence length preference with the quoted source.

Semantic frustration

“I feel like I’m being interviewed again.”

Action: reduce today’s question budget; record a contextual candidate—not a universal permanent rule.

Weak inference

The user often changes topics after advice.

Action: preserve as a low-confidence hypothesis with counterexamples; do not silently disable advice.

Quality gates without another model call

Deterministic draft checks

  • Word and token ceiling respected
  • Question count and stacked-question detection
  • Advice permitted for this turn
  • Every asserted memory maps to supplied evidence
  • Unsupported diagnosis and certainty language blocked
  • Deleted or withheld memories absent

Selective model review only when justified

  • Conflicting high-confidence memories
  • Sensitive memory would be mentioned explicitly
  • Deep formulation materially shaped the draft
  • High uncertainty or safety concern
  • Repeated recent user frustration

Optimization constitution

Optimize for

  • User agency and felt understanding
  • Preference compliance and factual accuracy
  • Useful continuity without intrusive callbacks
  • Appropriate restraint, uncertainty, and repair
  • Progress toward the user’s stated purpose for the conversation

Never optimize for

  • Time spent, message count, or daily dependence
  • Maximum disclosure or emotional intensity
  • Making Rosebud feel indispensable or human
  • Agreement, praise, or retention at the cost of honesty
  • Hidden psychological labels or inferred vulnerabilities

How should Rosebud improve its conversational behavior over time?

A

Consent-aware Preference Ledger + bounded outcome learning — recommended

Immediate adaptation, evidence-linked durable preferences, contextual scope, decay, user controls, and asynchronous outcome review.

B

Prompt reflection only

Ask the model to notice feedback within each session; simpler, but inconsistent across sessions and difficult to inspect or undo.

C

Autonomous self-optimizer

Continuously rewrite prompts or tune behavior from engagement signals; powerful, but opaque, unstable, and vulnerable to harmful incentives.
