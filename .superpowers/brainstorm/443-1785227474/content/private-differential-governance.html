Private Differential Layer · Governance for Option B

Option B can be explored only as a tightly governed reasoning aid. The system may consider diagnostic possibilities, but it may not convert them into secret identity, clinical truth, or an invisible treatment plan.

Rosebud does not announce the differential during normal conversation, but the user must know that this feature exists, whether it is enabled, when it ran, and how to disable or erase it.

When it may run

Required conditions

  • User explicitly enabled advanced differential reasoning
  • Scout finds sustained, multi-episode evidence—not one emotional sentence
  • The result could materially prevent a poor conversational response
  • Evidence quality, consent, privacy, latency, and model capability gates pass
  • A non-diagnostic formulation is generated in parallel as an anchoring check

Never enough by itself

  • A bad day, panic-like wording, grief, conflict, anger, or crying
  • One journal entry or one remembered traumatic event
  • A model recognizing stereotyped language
  • Demographics, culture, identity, or medication mention
  • Desire to personalize engagement or retention

Release gate

Required before enabling

  • Independent clinical-safety and privacy review
  • Longitudinal false-positive, anchoring, and subgroup evaluation
  • Adversarial testing for grief, trauma, neurodiversity, culture, and ordinary distress
  • Provider data-retention and training-use controls verified
  • Feature flag, small cohort, kill switch, and incident runbook

Automatic rollback signals

  • Diagnostic language leaks into user replies
  • Old differential biases unrelated conversations
  • Consent or deletion cascade fails
  • Subgroup false-positive rates exceed limits
  • Rosebud becomes more certain, prescriptive, or dependency-promoting

Option B implementation boundary

Which version of private diagnostic reasoning should enter the written design?

A

Opt-in, ephemeral private differential — recommended form of B

Multiple provisional possibilities, required non-clinical alternative, short retention, no durable diagnostic profile, and conservative conversational use.

B

User-visible durable diagnostic hypotheses

Encrypted and correctable hypotheses persist across sessions; improves continuity, but greatly increases anchoring, product-positioning, privacy, and governance burden.

C

Covert permanent diagnostic dossier — unsupported

Secret labels accumulate and steer future conversations. This is incompatible with user agency, a non-clinical companion, and trustworthy memory architecture.
