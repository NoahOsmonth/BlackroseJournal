Store evidence once. Represent change explicitly. Treat summaries, patterns, and indexes as rebuildable views—not permanent truth.

Layer 3 · Advisory learning, never hidden truth

Interaction preferences

  • Short replies when overwhelmed
  • Question budget 0–1
  • Advice only when requested
  • Explicit feedback has immediate authority
  • Context scope and expiry are recorded

Pattern hypotheses

  • Supporting episodes and counterexamples
  • Confidence, recency, and review date
  • Never converted into diagnosis
  • Never treated as identity
  • May decay or be dismissed

Deletion constitution
Deleting or editing source evidence invalidates every dependent artifact.

The dependency graph emits tombstones, removes retrieval eligibility immediately, queues rebuilds, verifies the cascade, and retains only the minimum audit record allowed by policy.

Truth-model baseline

Which foundation should the detailed cloud schema adopt?

A

Evidence-first, bitemporal model — recommended

Immutable sources, temporal claims, explicit uncertainty, hypotheses, and rebuildable projections.

B

Simple latest-value memory

One current value per fact; cheaper initially, but weak history, correction, and audit behavior.

C

Graph-first everything

All knowledge starts as nodes and edges; flexible, but harder to preserve raw evidence and transactional truth.
