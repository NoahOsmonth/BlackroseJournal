Quality, Cost & Latency Routing

Spend intelligence where the expected benefit is real. Normal conversation stays responsive with two model calls; ambiguity, sensitivity, or consequential reasoning may earn one additional specialist call.

The inputs are typed scores from semantic models and system state. There are no phrase lists such as “if panic, call the large model” or “if hi, skip memory.”

Model portfolio · capabilities, not brand loyalty

Fast structured model

Scout, candidate extraction, simple classification, schema repair. Optimized for low latency and reliable structured output.

Primary conversational model

Warmth, nuance, instruction following, long-context evidence use, restrained memory mention, and strong streaming quality.

Deep reasoning model

Ambiguous formulation, counterevidence, reconciliation, and the opt-in differential layer. Invoked sparingly.

Embedding model

Stable semantic index with model-version provenance, background re-embedding, and retrieval benchmarks before upgrades.

Cost controls that preserve quality

Save intelligently

  • Cache stable identity, preferences, recent retrieval, and query embeddings
  • Use compact evidence cards instead of raw transcript dumps
  • Batch background extraction, embedding, and consolidation
  • Use small models only after task-specific quality gates pass
  • Track cost by user, role, route, model, and outcome

Never save by

  • Dropping raw capture, corrections, deletion, or safety checks
  • Sending intimate journals to opaque “free” routing
  • Silently replacing Primary Rosebud with a poor model
  • Skipping provenance or validation on memory writes
  • Reducing context until the model starts inventing continuity

Routing baseline

How should the private Rosebud team trade quality, speed, and spend?

A

Adaptive expected-value routing — recommended

Two calls normally, three when justified, asynchronous curation, role-specific model benchmarks, hard deadlines, and measured cost per quality gain.

B

Largest model for every role

Simple and sometimes stronger, but slow, expensive, wasteful for extraction, and still not guaranteed to produce reliable structured memory.

C

Aggressive cost-first routing

Small models and minimal retrieval by default; affordable at scale, but incompatible with the stated maximum-quality priority.
