Failure behavior

Graceful degradation

  • Deadline expires → answer from the best verified brief already available
  • Deep retrieval fails → use recent context and say less, never invent
  • Scout unavailable → deterministic safe defaults and minimal retrieval
  • Background jobs never block the live response

Forbidden shortcuts

  • No “if message contains hi” routing
  • No full-year transcript dump into a prompt
  • No retrieved summary treated as unquestionable truth
  • No sensitive memory mentioned merely because it ranked highly

Live-turn baseline

Which retrieval contract should the detailed execution plan use?

A

Semantic preflight + progressive hybrid retrieval — recommended

Small Scout on every meaningful turn, parallel hybrid search, evidence-linked expansion, strict budgets, and a restrained brief.

B

Main-model tools only

Rosebud decides when to search while drafting; fewer moving parts, but inconsistent recall and weaker cost control.

C

Deep retrieval every turn

Maximum context each time; highest latency and cost, with more irrelevant or intrusive memory surfacing.
